# Escapes and entities

Use \`backticks\` literally, and write \[brackets\] without creating a link.

HTML entities: &copy; 2026 Contoso, &nbsp;non-breaking space, &lt;tag&gt; and &amp; ampersand.

Numeric entities: &#8364; (euro) and &#x2192; (arrow).

A backslash at the end of a line\
creates a hard line break.

Special characters: 50% off, #hashtag, @mention, 1 < 2 > 0, a | b.

Literal HTML-like text in code: `<div>` and `&amp;`.

The price is 10&nbsp;€ per month.

Escaped pipes in a table:

| Pattern | Meaning |
|---|---|
| `a\|b` | Either a or b |
| \* | Any character |
