# Toolbar reference

The editor toolbar contains the following buttons.

| Button | Shortcut | What it does |
|---|---|---|
| Run | F5 | Starts the current script |
| Stop | Shift+F5 | Ends the running script |
| Step | F10 | Runs the next line |
| Break | Ctrl+B | Sets a breakpoint on the current line |
| Clear | Ctrl+L | Empties the output pane |
| Save | Ctrl+S | Writes the file to disk |
| Open | Ctrl+O | Opens a file |
| Share | none | Copies a link to the script |
| Record | Ctrl+R | Records a macro |
| Play | Ctrl+P | Plays the last macro |

## Status bar

| Item | Values | Meaning |
|---|---|---|
| Mode | Edit, Read | Whether the file can be changed |
| Line | 1 to 99999 | Current line |
| Branch | main | Current Git branch |
| Sync | Up to date, Behind, Ahead | State compared with the remote |
