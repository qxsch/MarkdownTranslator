# Contoso Sync with Microsoft 365

Contoso Sync works with Microsoft Teams, SharePoint and OneDrive. Files that you sync with Contoso Sync can be opened in Word, Excel and PowerPoint for the web.

Azure Active Directory is now called Microsoft Entra ID. Sign in with your Entra ID account.

Use GitHub Actions or Azure Pipelines to deploy the agent. The Docker image is published to GitHub Container Registry.

Kubernetes users can deploy the Helm chart `contoso/sync-agent`. It works on Azure Kubernetes Service, Amazon EKS and Google Kubernetes Engine.

Visual Studio Code has an extension called *Contoso Sync Explorer*.
