# Admin center walkthrough

To change the default retention, go to **Settings** > **Data** > **Retention** and select **Edit**.

To add a user, select **Users** > **Active users** > **Add a user**. Fill in the **First name**, **Last name** and **Username** boxes, then select **Next**.

In the **Assign licenses** step, select **Team**. If the option is unavailable, you've run out of licenses. Select **Buy more** to add seats.

On the **Optional settings** page, you can assign a role. Leave **User (no admin center access)** selected for most people.

Select **Finish adding**. The user gets an e-mail with the subject *Your Contoso Sync account is ready*.

To remove a user, select the user, then **Delete user**. Deleted users can be restored for 30 days from **Users** > **Deleted users**.
