# Working with records

## Match

Select **Match** to find records with the same e-mail address. Matches are shown in a table.

## Scale

Use **Scale** to change the number of workers. A higher scale processes more records at the same time.

## Table

- **Freeze**: Keeps the first column visible while you scroll.
- **Drop**: Removes the table and all records in it.
- **Sort**: Orders the rows by the selected column.
- **Filter**: Shows only rows that meet a condition.

## Record

1. Select **Record**.
2. Perform the steps that you want to repeat.
3. Select **Stop**.

The recorded steps are saved as a macro.

## Park

When a record can't be processed, it's parked. Parked records wait in a separate queue until you select **Release**.

## Close

**Close** ends the period. After you close a period, records in it are read-only.

## Post

**Post** sends the record to the ledger. You can't undo a post, but you can post a reversal.
