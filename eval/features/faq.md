# Frequently asked questions

## Is my data encrypted?

Yes. Files are encrypted in transit with TLS 1.3 and at rest with AES-256. The keys are stored in a hardware security module.

## Can I sync network drives?

No. Only local folders are supported, because network drives don't report changes reliably.

## Why does the icon turn red?

A red icon means that at least one file couldn't be synced. Open the app and select **View problems** to see the list.

## How much does it cost?

The free plan includes 5 GB. The Team plan costs 4 euros per user and month and includes 1 TB per user.

## What happens when I run out of space?

Sync stops for new files. Existing files stay available, and you can free up space or upgrade at any time.

## Does it work offline?

Files that are marked as **Always keep on this device** are available offline. Changes are uploaded as soon as you're back online.

## Who can see my files?

Only you, unless you share a folder. Administrators can see file names in the audit log but not the content.
