# Settings reference

## General

| Setting | Values | Default |
|---|---|---|
| Start with Windows | On, Off | On |
| Language | Automatic, English, German, French | Automatic |
| Theme | Light, Dark, System | System |
| Updates | Automatic, Notify, Never | Automatic |

## Network

| Setting | Values | Default |
|---|---|---|
| Upload limit | None, Fixed, Adaptive | Adaptive |
| Download limit | None, Fixed | None |
| Proxy | None, System, Manual | System |
| Metered networks | Pause, Continue | Pause |

## Files

| Setting | Values | Default |
|---|---|---|
| Files on demand | On, Off | On |
| Free up space | Never, After 30 days, After 60 days | Never |
| Conflicts | Keep both, Keep newest, Ask | Keep both |
| Hidden files | Sync, Skip | Skip |

## Privacy

| Setting | Values | Default |
|---|---|---|
| Diagnostic data | Required, Optional | Required |
| Crash reports | Send, Ask, Never | Ask |
