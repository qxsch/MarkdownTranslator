# Platform notes

Jump to: [Windows setup](#setup) · [macOS setup](#setup-1) · [Linux setup](#setup-2) · [`ctsync` options](#ctsync-options) · [FAQ](#faq-)

## Windows

### Setup

Run the installer as a normal user.

### Known issues

Antivirus software can delay the first scan.

## macOS

### Setup

Drag the app to the **Applications** folder.

### Known issues

Grant full disk access in **System Settings**.

## Linux

### Setup

Install the package from the repository.

### Known issues

Some desktop environments don't show the tray icon.

## `ctsync` options

All platforms support the same options.
