# Template placeholders

Templates use curly braces for placeholders. For example, {name} is replaced with the user's name and {date} with today's date.

A comparison such as 1 < 2 or a < b is plain text in Markdown, and so is an arrow like <- or ->.

Write {{double braces}} to show a literal brace in the output.

Generic types such as List<string> and Map<K, V> appear in the SDK reference.

The e-mail subject is "Welcome, {firstName}!" by default. You can change it to anything, for example "Hi {firstName}, your folder {folder} is ready".

An HTML-like word such as <placeholder> in prose isn't a tag in the rendered page.
