# Your first week with Contoso Sync

Welcome aboard! This page shows you everything you need to get going.

## Day 1: Install the app

Grab the installer from the intranet and run it. Sign in with your new work account, and you're done.

## Day 2: Find your team folder

Your manager has already shared the team folder with you. Look for it under **Shared with me** and pin it so it shows up in File Explorer.

## Day 3: Try it out

Drop a file into the folder and watch it sync. Ask a colleague to open it. Pretty neat, huh?

## Stuck?

Ping the help desk in the #it-help channel. They're quick.
