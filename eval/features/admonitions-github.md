# Upgrade to version 4

> [!NOTE]
> Version 4 requires .NET 8 or later.

> [!TIP]
> Run `ctsync doctor` first. It lists everything that blocks the upgrade.

> [!IMPORTANT]
> **Back up** the file `config.toml` before you start. The upgrade rewrites it.

> [!WARNING]
> Don't close the app while the database is migrated. It can take up to an hour for large libraries.

> [!CAUTION]
> Downgrading to version 3 **deletes** all files that you created in version 4.

## Steps

1. Download the new version.
2. Close all Office apps.
3. Run the installer.
