# Keyboard shortcuts and advanced options

Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> to open the command palette.

<details>
<summary>Show all shortcuts</summary>

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save the file |
| <kbd>F2</kbd> | Rename the selected file |

</details>

<div class="warning">
  <p>Changing these options can <strong>slow down</strong> sync. Only change them when support asks you to.</p>
</div>
