# Glossary

**Share**
: A cloud folder that several people can access.

**Pin**
: Keeps a file on the device, even when files on demand is turned on.

**Placeholder**
: A file entry that shows the name and size but has no content on the device yet.

**Conflict copy**
: A second version of a file that is created when two people change the file at the same time. Its name ends with `-conflict`.

**Tenant**
: The organization that owns the accounts and the storage.

**Seat**
: A paid license for one user.

**Drain**
: Stops accepting new uploads on a server so that it can be updated.

**Throttle**
: Slows down requests from a client that sends too many.
