<a id="line-breaks-and-headings"></a>Sauts de ligne et titres
========================

Ce paragraphe se termine par deux espaces  
cette ligne commence donc après un saut de ligne forcé.

Celui-ci utilise une barre oblique inverse\
pour produire le même effet.

<a id="setext-level-two"></a>Setext de niveau deux
----------------

Un long paragraphe qui est renvoyé à la ligne dans le fichier source à une
largeur fixe afin que chaque ligne comporte moins de quatre-vingts
caractères, ce qui est courant dans les dépôts qui suivent un guide de style
strict pour les fichiers Markdown.

Un deuxième paragraphe avec des lignes
très courtes.

* * *

Séparateurs thématiques avec des astérisques et des traits de soulignement :

___

    This is an indented code block.
    It must stay exactly as it is.

Phrase finale.
