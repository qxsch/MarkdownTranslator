<a id="line-breaks-and-headings"></a>Sauts de ligne et titres
========================

Ce paragraphe se termine par deux espaces  
si bien que cette ligne commence après un saut de ligne forcé.

Celui-ci utilise une barre oblique inverse\
pour obtenir le même effet.

<a id="setext-level-two"></a>Setext de niveau deux
----------------

Un long paragraphe dont le texte est réparti sur plusieurs lignes dans le
fichier source selon une largeur fixe, de sorte que chaque ligne compte
moins de quatre-vingts caractères, ce qui est courant dans les dépôts qui
suivent un guide de style strict pour les fichiers Markdown.

Un deuxième paragraphe avec des lignes
très courtes.

* * *

Séparations thématiques avec des astérisques et avec des traits de soulignement :

___

    This is an indented code block.
    It must stay exactly as it is.

Phrase finale.
