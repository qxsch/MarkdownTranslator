# <a id="contoso-sync-with-microsoft-365"></a>Contoso Sync avec Microsoft 365

Contoso Sync fonctionne avec Microsoft Teams, SharePoint et OneDrive. Les fichiers que vous synchronisez avec Contoso Sync peuvent être ouverts dans Word, Excel et PowerPoint pour le web.

Azure Active Directory s’appelle désormais Microsoft Entra ID. Connectez-vous avec votre compte Entra ID.

Utilisez GitHub Actions ou Azure Pipelines pour déployer l’agent. L’image Docker est publiée dans GitHub Container Registry.

Les utilisateurs de Kubernetes peuvent déployer le chart Helm `contoso/sync-agent`. Il fonctionne sur Azure Kubernetes Service, Amazon EKS et Google Kubernetes Engine.

Visual Studio Code dispose d’une extension appelée *Contoso Sync Explorer*.
