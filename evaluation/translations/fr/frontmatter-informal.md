# <a id="your-first-week-with-contoso-sync"></a>Ta première semaine avec Contoso Sync

Bienvenue parmi nous ! Cette page te montre tout ce dont tu as besoin pour bien démarrer.

## <a id="day-1-install-the-app"></a>Jour 1 : installer l’application

Télécharge le programme d’installation depuis l’intranet et exécute-le. Connecte-toi avec ton nouveau compte professionnel, et c’est tout.

## <a id="day-2-find-your-team-folder"></a>Jour 2 : trouver ton dossier d’équipe

Ton responsable a déjà partagé le dossier d’équipe avec toi. Cherche-le sous **Partagé avec moi** et épingle-le pour qu’il s’affiche dans l’Explorateur de fichiers.

## <a id="day-3-try-it-out"></a>Jour 3 : faire un essai

Dépose un fichier dans le dossier et regarde-le se synchroniser. Demande à un collègue de l’ouvrir. Plutôt sympa, non ?

## <a id="stuck"></a>Bloqué ?

Envoie un message au support technique dans le canal #it-help. Ils répondent vite.
