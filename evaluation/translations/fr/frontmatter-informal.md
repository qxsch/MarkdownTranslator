# <a id="your-first-week-with-contoso-sync"></a>Ta première semaine avec Contoso Sync

Bienvenue à bord ! Cette page te montre tout ce dont tu as besoin pour démarrer.

## <a id="day-1-install-the-app"></a>Jour 1 : installe l’application

Récupère le programme d’installation depuis l’intranet et exécute-le. Connecte-toi avec ton nouveau compte professionnel, et c’est tout.

## <a id="day-2-find-your-team-folder"></a>Jour 2 : trouve ton dossier d’équipe

Ton responsable a déjà partagé le dossier d’équipe avec toi. Cherche-le dans **Partagé avec moi** et épingle-le pour qu’il apparaisse dans l’Explorateur de fichiers.

## <a id="day-3-try-it-out"></a>Jour 3 : essaie

Dépose un fichier dans le dossier et regarde la synchronisation se faire. Demande à un collègue de l’ouvrir. Plutôt sympa, non ?

## <a id="stuck"></a>Bloqué ?

Envoie un message au support technique dans le canal #it-help. Ils répondent vite.
