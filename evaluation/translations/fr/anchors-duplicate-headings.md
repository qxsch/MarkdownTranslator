## Windows

### <a id="setup"></a>Installation

Exécutez le programme d’installation en tant qu’utilisateur standard.

### <a id="known-issues"></a>Problèmes connus

Le logiciel antivirus peut retarder la première analyse.

## macOS

### <a id="setup-1"></a>Installation

Faites glisser l’application dans le dossier **Applications**.

### <a id="known-issues-1"></a>Problèmes connus

Accordez l’accès complet au disque dans **Réglages Système**.

## Linux

### <a id="setup-2"></a>Installation

Installez le paquet depuis le dépôt.

### <a id="known-issues-2"></a>Problèmes connus

Certains environnements de bureau n’affichent pas l’icône de la zone de notification.

## <a id="ctsync-options"></a>Options de `ctsync`

Toutes les plateformes prennent en charge les mêmes options.
