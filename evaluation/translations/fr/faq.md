# <a id="frequently-asked-questions"></a>Questions fréquentes

## <a id="is-my-data-encrypted"></a>Mes données sont-elles chiffrées ?

Oui. Les fichiers sont chiffrés en transit avec TLS 1.3 et au repos avec AES-256. Les clés sont stockées dans un module de sécurité matériel.

## <a id="can-i-sync-network-drives"></a>Puis-je synchroniser des lecteurs réseau ?

Non. Seuls les dossiers locaux sont pris en charge, car les lecteurs réseau ne signalent pas les modifications de manière fiable.

## <a id="why-does-the-icon-turn-red"></a>Pourquoi l’icône devient-elle rouge ?

Une icône rouge signifie qu’au moins un fichier n’a pas pu être synchronisé. Ouvrez l’application et sélectionnez **Afficher les problèmes** pour consulter la liste.

## <a id="how-much-does-it-cost"></a>Combien cela coûte-t-il ?

Le forfait gratuit inclut 5 Go. Le forfait Team coûte 4 euros par utilisateur et par mois et inclut 1 To par utilisateur.

## <a id="what-happens-when-i-run-out-of-space"></a>Que se passe-t-il lorsque je n’ai plus d’espace ?

La synchronisation s’arrête pour les nouveaux fichiers. Les fichiers existants restent disponibles, et vous pouvez libérer de l’espace ou passer à une offre supérieure à tout moment.

## <a id="does-it-work-offline"></a>Cela fonctionne-t-il hors connexion ?

Les fichiers marqués comme **Toujours conserver sur cet appareil** sont disponibles hors connexion. Les modifications sont envoyées dès que vous êtes de nouveau en ligne.

## <a id="who-can-see-my-files"></a>Qui peut voir mes fichiers ?

Vous seul, sauf si vous partagez un dossier. Les administrateurs peuvent voir les noms de fichiers dans le journal d’audit, mais pas le contenu.
