# <a id="share-a-folder"></a>Partager un dossier

Cliquez avec le bouton droit sur le dossier et sélectionnez **Partager**. Entrez les noms ou les adresses e-mail des personnes avec lesquelles vous souhaitez le partager.

## <a id="permissions"></a>Autorisations

- **Peut afficher** : les personnes peuvent ouvrir et télécharger des fichiers.
- **Peut modifier** : les personnes peuvent également modifier, ajouter et supprimer des fichiers.
- **Propriétaire** : les personnes peuvent également gérer le partage.

## <a id="external-users"></a>Utilisateurs externes

Les utilisateurs externes reçoivent un e-mail contenant un lien. Ils doivent vérifier leur adresse e-mail à l’aide d’un code à usage unique.
