# <a id="toolbar-reference"></a>Référence de la barre d’outils

La barre d’outils de l’éditeur contient les boutons suivants.

| Bouton | Raccourci | Fonction |
|---|---|---|
| Exécuter | F5 | Lance le script actuel |
| Arrêter | Maj+F5 | Met fin au script en cours d’exécution |
| Pas à pas | F10 | Exécute la ligne suivante |
| Point d’arrêt | Ctrl+B | Définit un point d’arrêt sur la ligne actuelle |
| Effacer | Ctrl+L | Vide le volet de sortie |
| Enregistrer | Ctrl+S | Écrit le fichier sur le disque |
| Ouvrir | Ctrl+O | Ouvre un fichier |
| Partager | aucun | Copie un lien vers le script |
| Enregistrer | Ctrl+R | Enregistre une macro |
| Lire | Ctrl+P | Exécute la dernière macro |

## <a id="status-bar"></a>Barre d’état

| Élément | Valeurs | Signification |
|---|---|---|
| Mode | Édition, Lecture | Indique si le fichier peut être modifié |
| Ligne | 1 à 99999 | Ligne actuelle |
| Branche | main | Branche Git actuelle |
| Synchronisation | À jour, En retard, En avance | État par rapport au dépôt distant |
