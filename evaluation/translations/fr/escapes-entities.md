# <a id="escapes-and-entities"></a>Échappements et entités

Utilisez les \`accents graves\` littéralement, et écrivez les \[crochets\] sans créer de lien.

Entités HTML : &copy; 2026 Contoso, &nbsp;espace insécable, &lt;balise&gt; et &amp; esperluette.

Entités numériques : &#8364; (euro) et &#x2192; (flèche).

Une barre oblique inverse en fin de ligne\
crée un saut de ligne forcé.

Caractères spéciaux : 50 % de réduction, #hashtag, @mention, 1 < 2 > 0, a | b.

Texte littéral de type HTML dans du code : `<div>` et `&amp;`.

Le prix est de 10&nbsp;€ par mois.

Barres verticales échappées dans un tableau :

| Modèle | Signification |
|---|---|
| `a\|b` | Soit a, soit b |
| \* | N’importe quel caractère |
