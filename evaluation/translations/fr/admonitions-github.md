# <a id="upgrade-to-version-4"></a>Mise à niveau vers la version 4

> [!NOTE]
> La version 4 nécessite .NET 8 ou une version ultérieure.

> [!TIP]
> Exécutez `ctsync doctor` d’abord. La commande répertorie tout ce qui bloque la mise à niveau.

> [!IMPORTANT]
> **Sauvegardez** le fichier `config.toml` avant de commencer. La mise à niveau le réécrit.

> [!WARNING]
> Ne fermez pas l’application pendant la migration de la base de données. Cela peut prendre jusqu’à une heure pour les bibliothèques volumineuses.

> [!CAUTION]
> Le retour à la version 3 **supprime** tous les fichiers que vous avez créés dans la version 4.

## <a id="steps"></a>Étapes

1. Téléchargez la nouvelle version.
2. Fermez toutes les applications Office.
3. Exécutez le programme d’installation.
