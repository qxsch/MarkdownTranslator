# <a id="admin-center-walkthrough"></a>Procédure pas à pas du centre d’administration

Pour modifier la rétention par défaut, accédez à **Paramètres** > **Données** > **Rétention**, puis sélectionnez **Modifier**.

Pour ajouter un utilisateur, sélectionnez **Utilisateurs** > **Utilisateurs actifs** > **Ajouter un utilisateur**. Renseignez les champs **Prénom**, **Nom** et **Nom d’utilisateur**, puis sélectionnez **Suivant**.

À l’étape **Attribuer des licences**, sélectionnez **Équipe**. Si l’option n’est pas disponible, vous n’avez plus de licences. Sélectionnez **Acheter davantage** pour ajouter des postes.

Sur la page **Paramètres facultatifs**, vous pouvez attribuer un rôle. Laissez **Utilisateur (aucun accès au centre d’administration)** sélectionné pour la plupart des utilisateurs.

Sélectionnez **Terminer l’ajout**. L’utilisateur reçoit un e-mail dont l’objet est *Votre compte Contoso Sync est prêt*.

Pour supprimer un utilisateur, sélectionnez l’utilisateur, puis **Supprimer l’utilisateur**. Les utilisateurs supprimés peuvent être restaurés pendant 30 jours via **Utilisateurs** > **Utilisateurs supprimés**.
