# <a id="restore-deleted-files"></a>Restaurer des fichiers supprimés

## <a id="recycle-bin"></a>Corbeille

Ouvrez la corbeille dans l’application web, sélectionnez les fichiers, puis sélectionnez **Restaurer**.

## <a id="version-history"></a>Historique des versions

Cliquez avec le bouton droit sur un fichier et sélectionnez **Historique des versions**. Sélectionnez une version, puis sélectionnez **Restaurer**.
