# <a id="sharing-roles"></a>Rôles de partage

<RoleCard role="viewer" title="Lecteur" description="Peut ouvrir et télécharger des fichiers." icon="eye" />

<RoleCard role="editor" title="Éditeur" description="Peut modifier, ajouter et supprimer des fichiers." icon="pencil" />

<Admonition type="tip" title="Moindre privilège">
  Attribuez aux personnes le rôle **le plus restreint** qui leur permet d’effectuer leur travail.
</Admonition>

<Steps>
  <Step title="Sélectionner le dossier">Cliquez avec le bouton droit sur le
dossier dans l’Explorateur de fichiers.</Step> <Step title="Choisir un rôle">Choisissez
*Lecteur* ou *Éditeur* dans la liste.</Step> <Step title="Envoyer l’invitation">Sélectionnez
**Envoyer**.</Step>
</Steps>
