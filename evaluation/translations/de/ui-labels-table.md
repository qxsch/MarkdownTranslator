# <a id="toolbar-reference"></a>Symbolleistenreferenz

Die Symbolleiste des Editors enthält die folgenden Schaltflächen.

| Schaltfläche | Tastenkombination | Funktion |
|---|---|---|
| Ausführen | F5 | Startet das aktuelle Skript |
| Beenden | Umschalt+F5 | Beendet das laufende Skript |
| Schritt | F10 | Führt die nächste Zeile aus |
| Haltepunkt | Strg+B | Legt einen Haltepunkt in der aktuellen Zeile fest |
| Leeren | Strg+L | Leert den Ausgabebereich |
| Speichern | Strg+S | Schreibt die Datei auf den Datenträger |
| Öffnen | Strg+O | Öffnet eine Datei |
| Teilen | Keine | Kopiert einen Link zum Skript |
| Aufzeichnen | Strg+R | Zeichnet ein Makro auf |
| Wiedergeben | Strg+P | Spielt das letzte Makro ab |

## <a id="status-bar"></a>Statusleiste

| Element | Werte | Bedeutung |
|---|---|---|
| Modus | Bearbeiten, Lesen | Ob die Datei geändert werden kann |
| Zeile | 1 bis 99999 | Aktuelle Zeile |
| Branch | main | Aktueller Git-Branch |
| Sync | Auf dem neuesten Stand, Zurück, Voraus | Status im Vergleich zum Remote-Repository |
