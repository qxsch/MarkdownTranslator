# <a id="working-with-records"></a>Arbeiten mit Datensätzen

## <a id="match"></a>Abgleichen

Wählen Sie **Abgleichen** aus, um Datensätze mit derselben E-Mail-Adresse zu finden. Übereinstimmungen werden in einer Tabelle angezeigt.

## <a id="scale"></a>Skalieren

Verwenden Sie **Skalieren**, um die Anzahl der Worker zu ändern. Bei einer höheren Skalierung werden mehr Datensätze gleichzeitig verarbeitet.

## <a id="table"></a>Tabelle

- **Einfrieren**: Sorgt dafür, dass die erste Spalte beim Scrollen sichtbar bleibt.
- **Löschen**: Entfernt die Tabelle und alle darin enthaltenen Datensätze.
- **Sortieren**: Sortiert die Zeilen nach der ausgewählten Spalte.
- **Filtern**: Zeigt nur Zeilen an, die eine Bedingung erfüllen.

## <a id="record"></a>Aufzeichnen

1. Wählen Sie **Aufzeichnen** aus.
2. Führen Sie die Schritte aus, die Sie wiederholen möchten.
3. Wählen Sie **Stopp** aus.

Die aufgezeichneten Schritte werden als Makro gespeichert.

## <a id="park"></a>Parken

Wenn ein Datensatz nicht verarbeitet werden kann, wird er geparkt. Geparkte Datensätze warten in einer separaten Warteschlange, bis Sie **Freigeben** auswählen.

## <a id="close"></a>Schließen

**Schließen** beendet die Periode. Nachdem Sie eine Periode geschlossen haben, sind die darin enthaltenen Datensätze schreibgeschützt.

## <a id="post"></a>Buchen

**Buchen** sendet den Datensatz an das Hauptbuch. Sie können eine Buchung nicht rückgängig machen, aber Sie können eine Stornobuchung buchen.
