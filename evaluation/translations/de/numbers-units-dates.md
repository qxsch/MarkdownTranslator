# <a id="limits-and-quotas"></a>Grenzwerte und Kontingente

| Grenzwert | Wert |
|---|---|
| Maximale Dateigröße | 250 GB |
| Maximale Pfadlänge | 400 Zeichen |
| Dateien pro Freigabe | 30,000,000 |
| Anforderungen pro Minute | 1.200 pro Benutzer |
| Upload-Geschwindigkeit | Bis zu 1,5 Gbit/s |

Der Dienst verarbeitet in Spitzenzeiten 3,5 Millionen Dateien pro Stunde. Das letzte Wartungsfenster war am 14. August 2026 von 01:00 bis 03:30 UTC.

Die Aufbewahrung kann auf einen Wert zwischen 1 und 3.650 Tagen festgelegt werden. Der Standardwert von 93 Tagen entspricht dem Papierkorb.

Version 3.2 hat die durchschnittliche Synchronisierungsverzögerung von 2,4 s auf 0,8 s reduziert, was 66,7 % schneller ist.

Tarife beginnen bei 4,50 EUR pro Benutzer und Monat bei jährlicher Abrechnung (54 EUR pro Jahr).
