# <a id="keyboard-shortcuts-and-advanced-options"></a>Tastenkombinationen und erweiterte Optionen

Drücken Sie <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>, um die Befehlspalette zu öffnen.

<details>
<summary>Alle Tastenkombinationen anzeigen</summary>

| Tastenkombination | Aktion |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Datei speichern |
| <kbd>F2</kbd> | Ausgewählte Datei umbenennen |

</details>

<div class="warning">
  <p>Das Ändern dieser Optionen kann die Synchronisierung <strong>verlangsamen</strong>. Ändern Sie sie nur, wenn der Support Sie dazu auffordert.</p>
</div>

<table>
  <tr><th>Option</th><th>Auswirkung</th></tr>
  <tr><td><code>max_workers</code></td><td>Anzahl paralleler Uploads</td></tr>
  <tr><td><code>chunk_size</code></td><td>Größe jedes Upload-Blocks in Byte</td></tr>
</table>
