# <a id="restore-deleted-files"></a>Gelöschte Dateien wiederherstellen

## <a id="recycle-bin"></a>Papierkorb

Öffnen Sie den Papierkorb in der Web-App, wählen Sie die Dateien aus, und wählen Sie **Wiederherstellen**.

## <a id="version-history"></a>Versionsverlauf

Klicken Sie mit der rechten Maustaste auf eine Datei, und wählen Sie **Versionsverlauf** aus. Wählen Sie eine Version und dann **Wiederherstellen** aus.
