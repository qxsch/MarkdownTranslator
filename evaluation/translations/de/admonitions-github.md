# <a id="upgrade-to-version-4"></a>Upgrade auf Version 4

> [!NOTE]
> Version 4 erfordert .NET 8 oder höher.

> [!TIP]
> Führen Sie `ctsync doctor` zuerst aus. Es listet alles auf, was das Upgrade blockiert.

> [!IMPORTANT]
> **Sichern Sie** die Datei `config.toml`, bevor Sie beginnen. Beim Upgrade wird die Datei neu geschrieben.

> [!WARNING]
> Schließen Sie die App nicht, während die Datenbank migriert wird. Bei großen Bibliotheken kann dies bis zu einer Stunde dauern.

> [!CAUTION]
> Ein Downgrade auf Version 3 **löscht** alle Dateien, die Sie in Version 4 erstellt haben.

## <a id="steps"></a>Schritte

1. Laden Sie die neue Version herunter.
2. Schließen Sie alle Office-Apps.
3. Führen Sie das Installationsprogramm aus.

> Dies ist ein normales Zitat. Es ist kein Hinweisblock, sollte aber ebenfalls übersetzt werden.
