# <a id="configure-retention"></a>Aufbewahrung konfigurieren

:::note
Die Aufbewahrung gilt für gelöschte Dateien und für alte Versionen.
:::

:::tip Speicherplatz sparen
Legen Sie für Ordner mit großen Mediendateien eine kurze Aufbewahrungsdauer fest.
:::

:::info[Aufbewahrung und gesetzliche Aufbewahrungspflicht]
Dateien, die einer **gesetzlichen Aufbewahrungspflicht** unterliegen, werden auch nach Ablauf der Aufbewahrungsdauer aufbewahrt.
:::

:::warning

Die Aufbewahrungseinstellung wirkt sich auf **alle** Mitglieder der Freigabe aus.

:::

:::danger Unumkehrbar
Dateien, die durch die Aufbewahrungsrichtlinie gelöscht werden, können nicht wiederhergestellt werden.
:::

## <a id="choose-a-period"></a>Zeitraum auswählen

Die meisten Teams bewahren Versionen 30 Tage lang auf. Regulierte Branchen benötigen häufig eine Aufbewahrungsdauer von 7 Jahren.
