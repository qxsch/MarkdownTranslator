# <a id="admin-center-walkthrough"></a>Exemplarische Vorgehensweise für das Admin Center

Um die Standardaufbewahrung zu ändern, wechseln Sie zu **Einstellungen** > **Daten** > **Aufbewahrung**, und wählen Sie **Bearbeiten** aus.

Um einen Benutzer hinzuzufügen, wählen Sie **Benutzer** > **Aktive Benutzer** > **Benutzer hinzufügen** aus. Füllen Sie die Felder **Vorname**, **Nachname** und **Benutzername** aus, und wählen Sie dann **Weiter** aus.

Wählen Sie im Schritt **Lizenzen zuweisen** die Option **Team** aus. Wenn die Option nicht verfügbar ist, sind Ihre Lizenzen aufgebraucht. Wählen Sie **Weitere kaufen** aus, um Lizenzplätze hinzuzufügen.

Auf der Seite **Optionale Einstellungen** können Sie eine Rolle zuweisen. Lassen Sie für die meisten Personen **Benutzer (kein Admin-Center-Zugriff)** ausgewählt.

Wählen Sie **Hinzufügen abschließen** aus. Der Benutzer erhält eine E-Mail mit dem Betreff *Ihr Contoso Sync-Konto ist bereit*.

Um einen Benutzer zu entfernen, wählen Sie den Benutzer und dann **Benutzer löschen** aus. Gelöschte Benutzer können 30 Tage lang über **Benutzer** > **Gelöschte Benutzer** wiederhergestellt werden.
