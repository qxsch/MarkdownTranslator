# <a id="glossary"></a>Glossar

**Freigabe**: Ein Cloud-Ordner, auf den mehrere
Personen zugreifen können.

**Anheften**: Behält eine Datei auf dem Gerät, auch wenn „Dateien bei
Bedarf“ aktiviert ist.

**Platzhalter**: Ein Dateieintrag, der Name und Größe anzeigt, dessen Inhalt sich
jedoch noch nicht auf dem Gerät befindet.

**Konfliktkopie**: Eine zweite Version einer Datei, die erstellt wird, wenn zwei Personen die Datei gleichzeitig ändern. Ihr
Name endet mit `-conflict`.

**Mandant**: Die Organisation, der die Konten und der
Speicher gehören.

**Lizenzplatz**: Eine kostenpflichtige
Lizenz für einen Benutzer.

**Drain**: Nimmt keine neuen Uploads auf einem Server mehr an, damit
dieser aktualisiert werden kann.

**Drosselung**: Verlangsamt Anforderungen von einem
Client, der zu viele sendet.
