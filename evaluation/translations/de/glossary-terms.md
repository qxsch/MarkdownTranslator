# <a id="glossary"></a>Glossar

**Freigabe** : Ein Cloud-Ordner, auf den mehrere
Personen zugreifen können.

**Anheften** : Bewirkt, dass eine Datei auf dem Gerät gespeichert
bleibt, auch wenn „Dateien bei Bedarf“ aktiviert ist.

**Platzhalter** : Ein Dateieintrag, der den Namen und die Größe anzeigt, aber
noch keinen Inhalt auf dem Gerät hat.

**Konfliktkopie** : Eine zweite Version einer Datei, die erstellt wird, wenn zwei Personen die Datei gleichzeitig ändern. Ihr
Name endet auf `-conflict`.

**Mandant** : Die Organisation, der die Konten und der
Speicher gehören.

**Lizenzplatz** : Eine kostenpflichtige
Lizenz für einen Benutzer.

**Leerlaufen lassen**: Sorgt dafür, dass ein Server keine neuen
Uploads mehr annimmt, damit er aktualisiert werden kann.

**Drosseln** : Verlangsamt Anforderungen von einem
Client, der zu viele sendet.
